## Session: Web app scaffold and coloring engine (milestone 1)
**Done**
- Scaffolded Vite + TypeScript with no UI framework (ADR 0002), Vitest and Playwright (ADR 0015), and
  `.github/workflows/ci.yml` running typecheck, unit tests and browser tests.
- App shell (ADR 0012): game registry with the coloring game lazy-loaded, kid picker, home screen (skipped with
  one game), storage interface backed by IndexedDB (ADR 0007), escape-hatch guards (ADR 0003 rule 4). The app
  draws on the 1280 × 800 reference frame and scales it to fit the window.
- Crayon Box tokens as CSS custom properties with the names and values from the design system's `tokens.json`,
  and the kid components the coloring screens need (ADR 0016).
- Coloring engine (ADR 0004): paper, paint and line canvases at 2048 × 1536; region map and region masks in a
  worker; bucket with 2 px growth under lines and nearest region within 8 px; brush and eraser, one stroke per
  finger up to four, palms ignored; stay in the lines per picture; rainbow; undo capped at 20 steps or 150 MB;
  start over as one undo step.
- Coloring screen laid out as the mockup: tool rail, page, color rail three wide, tray with sizes and modes.
- A simple page picker (tiles only, no theme strip) and autosave 1 s after an action and on leaving, with
  `prev.png` kept on reopen (ADR 0007). A started page's tile shows the kid's coloring.
- Three original CC0 placeholder pages: shapes, a fish, a cartoon race car (face on the bumper).
- 46 unit tests and 10 browser tests pass locally. Checked by hand in the browser pane at 1280 × 800.

**Learned**
