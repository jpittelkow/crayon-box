## Session: sync server on Unraid, and picking the AI model
**Done**
- The sync server (1.1.0) runs on the family's Unraid machine from the published image, added as a user template
  so it updates from Unraid's Docker page (Unraid's update check reads the image from GitHub's registry). A device
  is paired; the owner set the OpenRouter key and AI pages are on.
- Picking the AI model in the app ([ADR 0032](../adr/0032-pick-the-ai-model-in-the-app.md), asked by the owner):
  the server serves OpenRouter's model list sorted by way of making a page (`GET /api/v1/ai/models`), keeps the
  family's favorites (`PUT /api/v1/ai/favorites`), and takes a `model` per page. Add pages › Make a page with AI
  has a Model dropdown (server default, favorites, all models, a search box, a price), a ★ button, and says which
  model made the page. Each device remembers its pick per way under `local/`. App 0.5.0, server 1.2.0.

  for what OpenRouter's list says the model gives back.
